# Stage 1 UML Editing Files

All files describe the Stage 1 class-design proposal. The same diagram is included in the English design PDF.

| File | Purpose |
| --- | --- |
| [Stage_1_Class_Diagram.drawio](Stage_1_Class_Diagram.drawio) | Open in diagrams.net (draw.io) to edit class boxes, attributes, methods, connectors, and multiplicity labels. This is a native diagram, not a flattened image. |
| [Stage_1_Class_Diagram.mmd](Stage_1_Class_Diagram.mmd) | Editable Mermaid class-diagram source. Change class members and relationships in a Mermaid-compatible editor, then export again. |
| [Stage_1_Class_Diagram.svg](Stage_1_Class_Diagram.svg) | Scalable vector image for zooming, placement in reports, and vector editing. |
| [Stage_1_Class_Diagram.png](Stage_1_Class_Diagram.png) | Image for quick preview and sharing. Use the native or text source for structural edits. |

## Editing workflow

1. Choose the draw.io or Mermaid source as the working source for the next revision.
2. Update class responsibilities, members, relationships, and multiplicities consistently.
3. Export matching SVG and PNG previews.
4. Update the design text and regenerate the PDF when the agreed design changes.

The draw.io file contains 10 editable class nodes and 15 editable relationships. Connector routing can be adjusted in the editor. The Mermaid source and draw.io file are separate formats, so keep their semantics synchronized when editing.
